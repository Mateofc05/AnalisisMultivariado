4. Hipótesis

Queremos determinar si el vector de medias de la tinta confiscada coincide con el perfil oficial:

\[ H_0:\boldsymbol{\mu}=\boldsymbol{\mu}_0 \]

\[ H_a:\boldsymbol{\mu}\neq\boldsymbol{\mu}_0 \]

La hipótesis alternativa es multivariada: basta con que la media de al menos una de las características difiera para que los vectores no sean iguales.

5. Estadística \(T^2\) de Hotelling para una muestra

La estadística se calcula con

\[ T^2=n(\bar{\mathbf{x}}-\boldsymbol{\mu}_0)^T S^{-1}(\bar{\mathbf{x}}-\boldsymbol{\mu}_0), \]

donde \(S\) es la matriz de covarianzas muestral.

x_barra = X.mean().to_numpy()
S = X.cov().to_numpy()
diferencia = x_barra - mu_0

# solve(S, diferencia) es numéricamente preferible a calcular inv(S).
T2 = float(n * diferencia.T @ np.linalg.solve(S, diferencia))

comparacion_medias = pd.DataFrame(
    {
        "media_confiscada": x_barra,
        "media_oficial_mu0": mu_0,
        "diferencia": diferencia,

    index=columnas_ink,

6. Región de rechazo con \(\alpha=0.05\)

Bajo \(H_0\), la transformación

\[ F=\frac{n-p}{p(n-1)}T^2 \]

sigue una distribución \(F\) con \(p\) y \(n-p\) grados de libertad. Por ello, rechazamos \(H_0\) cuando

\[ T^2>\frac{p(n-1)}{n-p}F_{p,n-p;\,1-\alpha}. \]

alpha = 0.05

F_calculada = ((n - p) / (p * (n - 1))) * T2
F_critica = stats.f.ppf(1 - alpha, dfn=p, dfd=n - p)
T2_critica = (p * (n - 1) / (n - p)) * F_critica
valor_p = stats.f.sf(F_calculada, dfn=p, dfd=n - p)

print(f"F calculada = {F_calculada:.4f}")
print(f"F crítica = {F_critica:.4f}")
print(f"T² calculada = {T2:.4f}")
print(f"T² crítica = {T2_critica:.4f}")
print(f"Valor p = {valor_p:.4e}")
